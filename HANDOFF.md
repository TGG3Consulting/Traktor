## Что появилось за ночь 14→15 августа

### Чат (§2.12)
Одна ветка на пару «задание + исполнитель». До подтверждения сделки телефоны,
ники мессенджеров и почта заменяются точками, а отправитель получает понятное
объяснение — почему так и когда номер откроется. После сделки контакты не
прячутся. Есть непрочитанные, отметка прочтения при открытии и уведомление
собеседнику. Вход в переписку — из отклика, деталки задания и сделки.

### Оценки и отзывы (§2.13)
Пять звёзд обязательны, отметки — закрытым списком под роль («Пунктуально» для
исполнителя, «Чёткое ТЗ» для заказчика), текст до 500 символов. Отзывы
открываются **одновременно** после обеих оценок либо через неделю: так оценка
не подстраивается под чужую и не превращается в месть. Ответить на отзыв о себе
можно один раз. Рейтинг считается за последние 12 месяцев и виден в карточках
откликов и сделки.

### Центр уведомлений и настройки (§2.14)
Каждое событие сохраняется в ленту до отправки push: телефон мог быть выключен,
а событие человек всё равно увидит. Вкладка «Сообщения» получила переключатель
«Чаты / Уведомления», нажатие на событие ведёт на нужный экран. В профиле —
тумблеры по группам (аукционы, сделки, чат, новые задания, новости), рассылка
только по согласию, тихие часы 22:00–08:00 с исключением «перебили ставку» по
выбору человека. Выключенная группа глушит только push — событие всё равно в
центре уведомлений.

### Моя техника (§2.5)
Визард четырёх шагов с автосохранением: категория из справочника → марка,
модель, год, характеристики по шаблону категории, тарифы аренды и бригада →
фотографии → документы. С документами карточка уходит на проверку, без них
публикуется сразу как «Без проверки»: работать можно, но в скоринге ниже.
Пока карточка на проверке, править её нельзя. Откликаться и делать ставки
можно только своей опубликованной техникой.

### Фотографии (ADR-5)
Появился сервис **media**: он выдаёт временную ссылку, а файл уходит от телефона
прямо в хранилище, минуя наш сервер. Локально это MinIO, в бою — Cloudflare R2,
переключение сводится к смене адреса и ключей. Приложение сжимает снимки до
1600 пикселей. Фото есть и у техники, и у заданий: в деталке они идут лентой
над характеристиками.

### Карточка человека (§2.3)
Имя, город, «на площадке с», рейтинг, опубликованная техника и отзывы с
ответами. Открыта по ссылке без входа — такой ссылкой делятся в мессенджере.
Телефон не отдаётся никогда: до сделки он скрыт, в сделке приходит отдельно.

### CRM исполнителя, первая часть (§3.1)
Экран «Мой бизнес»: доход за выбранный период и насколько он изменился к
прошлому такому же отрезку, средний чек, воронка «откликнулся → выбрали →
завершил» и клиентская база с бейджем «Постоянный» с третьей сделки. Ничего
заполнять руками не нужно — цифры собираются из завершённых сделок.

### Живые обновления (ADR-6)
Ставка, продление торга и сообщение в переписке доходят до открытых экранов за
доли секунды. В каждом событии время сервера — таймер финиша идёт одинаково у
всех, как бы ни врали часы на телефоне. Лента торга остаётся анонимной: имён в
событиях нет. Канал переписки закрыт — подписаться можно только по билету,
который выдаётся участнику чата.

## Что работает целиком (из прошлых сессий)

- **Задания (§2.6–2.8)**: визард пяти шагов с черновиком, лента на PostGIS с
  радиусом и сортировками, деталка со счётчиком просмотров и скрытым резервом.
- **Отклики (§2.10)**: приём цены или своя цена, один раунд встречной цены,
  выбор исполнителя с автозакрытием остальных.
- **Аукцион (§2.9)**: ставки ниже лучшей и не ниже трети старта, антиснайпинг
  +10 минут, запрет отзыва за 2 часа, анонимная лента, скоринг 0.6/0.25/0.15,
  окно решения заказчика.
- **Сделка (§2.11)**: общий таймлайн, шаги строго по порядку и по сторонам,
  48 часов на приёмку, отмена с причиной.
- **Время само доводит дела до конца**: финиш торга, закрытие по молчанию,
  автоприёмка, публикация одиноких отзывов через неделю.

## Что нашлось при живой проверке этой ночью (и починено)

- Переписка читалась снизу вверх: ответы оказывались раньше вопросов.
- Черновик техники не создавался, пока не выбрана категория, — падал на пустом
  идентификаторе категории.
- Ссылки вида `/equipment/$id` уходили на сервер буквально, с долларом.
- Десять сквозных проверок подряд упирались в боевой лимит 100 запросов в
  минуту; на локальном стенде лимит поднят, в бою остался прежним.
- Фоновый помощник зависал на задании с `findstr` в конвейере; заодно `env.bat`
  теперь собирает PATH заново, а не дописывает его до предела Windows.

## Чем проверять (запускается само, окон не открывает)

| Скрипт | Что проверяет |
|---|---|
| `scripts\jobs-check.ps1` | черновик → шаги → публикация → лента → деталка → отмена |
| `scripts\offers-check.ps1` | отклики, встречная цена, выбор исполнителя |
| `scripts\deal-check.ps1` | подтверждение → выехал → работает → завершил → приёмка |
| `scripts\auction-check.ps1` | ставки, антидемпинг, финиш, скоринг, выбор победителя |
| `scripts\chat-check.ps1` | переписка, маскировка контактов, непрочитанные |
| `scripts\review-check.ps1` | оценки, одновременная публикация, ответ на отзыв |
| `scripts\center-check.ps1` | центр уведомлений и отметка прочтения |
| `scripts\prefs-check.ps1` | настройки уведомлений и тихие часы |
| `scripts\equipment-check.ps1` | визард техники, публикация, модерация |
| `scripts\media-check.ps1` | ссылка → загрузка файла → чтение по адресу |
| `scripts\profile-check.ps1` | карточка человека, техника и отзывы в ней |
| `scripts\realtime-check.ps1` | билет на подключение, ставка и сообщение в канале |
| `scripts\crm-check.ps1` | доход, воронка и клиентская база исполнителя |
| `scripts\live-check.ps1` | внешние адреса homly.am живы, вход по 000000 работает |
| `scripts\seed-demo.ps1` | демо-данные для ручной проверки в браузере |

Задание помощнику — файл `.bat` в `scripts\_queue`, результат — в `scripts\_out`.
Если помощник перестал разбирать очередь, запустите `scripts\restart-agent.bat`.
