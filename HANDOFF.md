## Что сделано в эту ночь

### Модуль «Задания» — первый полный цикл до сделки

**Сервис `catalog`** — дерево категорий работ и техники. Названия на трёх
языках, у каждой категории шаблон характеристик: из него приложение строит
поля визарда, поэтому новая категория не требует правок клиента.

**Сервис `orders`** — задания:
- черновик визарда автосохраняется после каждого шага; на главной заказчика он
  виден как «Черновик · шаг 3 из 5 · продолжить»;
- проверка полноты на сервере: при нехватке данных приходит разбор по полям, и
  экран подсвечивает именно то, чего не хватает;
- публикация: фикс-цена уходит собирать отклики, аукцион — в торги, время
  финиша считает сервер;
- лента на PostGIS: радиус, категории, режим, поиск, четыре сортировки,
  расстояние до каждого задания;
- деталка: просмотры считаются «один человек — один просмотр», свои не в счёт;
  резервную цену аукциона сервер отдаёт только владельцу задания;
- отклики (§2.10): согласие с ценой или своя цена, повторный отклик обновляет
  предложение вместо дубля, отзыв, отклонение с причиной, **один** раунд
  встречной цены заказчика, выбор исполнителя — остальные предложения
  закрываются автоматически, задание уходит в «ожидает подтверждения».

**Уведомления** — orders сообщает notifications о новом отклике, встречной цене,
выборе и отказе. Провайдер пока fake: рассылка доходит до сервиса и пишется в
лог, реальная доставка включится вместе с Firebase.

**Приложение**: визард из пяти шагов, главная заказчика, лента исполнителя,
деталка для обеих ролей, экран откликов, шит отклика, вкладка «Мои ставки»,
экран после публикации со ссылкой для шеринга.

### Что нашлось при живой проверке (и починено)

- Ответы сервера читались не в UTF-8 — русский текст ошибок превращался в
  «Ð¡ÐµÑÑÐ¸Ñ».
- Истёкший через 15 минут токен выбрасывал из приложения. Теперь обновляется
  сам, один общий запрос на всё приложение.
- Обновления приложения не доезжали до телефона: раздача разрешала браузеру
  хранить код неделю. Теперь ссылка на код получает метку сборки, и новая
  версия приходит сразу.
- На широком экране макет растягивался на весь монитор — держим телефонную
  ширину по центру.
- Мелочи: «1 откликов», «0 м» вместо «рядом», сырые ключи справочника («soft»
  вместо «Мягкий»), иконка загрузки вместо стрелки «назад».

## Чем проверять (всё запускается само, окон не открывает)

| Скрипт | Что проверяет |
|---|---|
| `scripts\jobs-check.ps1` | сквозной путь: вход → справочник → черновик → шаги → публикация → лента → деталка → скрытый резерв → отмена → данные в базе |
| `scripts\offers-check.ps1` | отклики: два исполнителя, встречная цена, запрет второго раунда, выбор, автоотклонение остальных |
| `scripts\notify-check.ps1` | уведомления доходят до сервиса notifications |
| `scripts\live-check.ps1` | внешние адреса homly.am живы, вход по 000000 работает |
| `scripts\flutter-check.ps1` | анализ и тесты трёх Flutter-пакетов |
| `scripts\build-svc.ps1 <сервис>` | сборка, vet и тесты одного Go-сервиса |
| `scripts\deploy-web.ps1` | сборка и выкладка приложения с меткой версии |

Все они кладутся в очередь помощнику: файл `.bat` в `scripts\_queue`, результат —
в `scripts\_out`.

## Что ждёт от Тиграна

1. **Firebase Project ID** — включит реальные push-уведомления (сейчас fake).
2. **Ключ MapTiler** — включит карту в ленте и на шаге «Где» (сейчас место
   задаётся городом и адресом).
3. **Cloudflare R2** — включит фотографии заданий (сейчас поле есть, загрузки нет).

Ни одно из этого не блокирует остальную разработку.
