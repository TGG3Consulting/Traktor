feat(infra): компьютер отдаёт приложение наружу через homly.am

Cloudflare Tunnel: api.homly.am → шлюз, rt.homly.am → Centrifugo,
app.homly.am → собранное веб-приложение. Белый IP и проброс портов не нужны,
https выдаёт Cloudflare. Переезд в облако = поменять адреса в ingress туннеля
или переключить DNS на Cloud Run; приложение и сервисы не меняются.

Веб-приложение раздаёт nginx в Docker (infra/local/nginx-web.conf): SPA-роутинг,
кэш для ресурсов с хэшем в имени и запрет кэша для index.html, иначе пользователи
залипали бы на старой версии.

Centrifugo: включён эндпоинт /health (по умолчанию выключен, из-за чего проверка
снаружи возвращала 404) и сужен список разрешённых источников до app.homly.am.

Скрипты: tunnel-up (создание туннеля и DNS-записей), go-live (собрать всё,
запустить и проверить снаружи), live-check (4 проверки внешних адресов).

Проверено снаружи: healthz шлюза 200, полный вход по коду 000000 через интернет,
приложение отдаётся, realtime отвечает.
