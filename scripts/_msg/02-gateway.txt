refactor(gateway): jwx для JWKS, httprate для лимитов, chi и go-chi/cors

Убраны самописные разбор JWT, загрузка JWKS и счётчик запросов на IP
(правило 23). Проверка токенов — jwx jwk.Cache + golang-jwt/jwt/v5,
ограничение частоты — go-chi/httprate, CORS — go-chi/cors, роутер — chi/v5.

Ротация ключа больше не роняет вход: при неизвестном kid набор ключей
обновляется на месте. Ошибка регистрации JWKS-кэша больше не глушится —
шлюз сообщает о ней на старте, а не отвергает молча все токены.

Reverse-proxy переведён с устаревшего Director на Rewrite с SetXForwarded:
клиент не может подделать заголовки X-Forwarded-*.

Добавлен тест на подмену алгоритма (HS256 с публичным ключом отклоняется).
main: log/slog и корректное завершение по сигналу.
