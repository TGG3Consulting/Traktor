# Что установить на твой компьютер (Windows) — для новичка
**Дата: 13.08.2026. Коротко: минимум сейчас, тяжёлое — по желанию/позже. Я на Windows-компе (C:\Traktor).**

## Короткий ответ
Ставим сейчас **всего 2 программы** (обе бесплатные, простые). Тяжёлый инструментарий для сборки приложения ставить НЕ обязательно — приложение может собираться автоматически в облаке, а ты просто открываешь ссылку или ставишь готовый файл. Полную установку для разработки покажу отдельно, если захочешь собирать сам.

---

## 1. Ставим сейчас (5 минут, бесплатно)

### а) VS Code — «блокнот для кода»
Чтобы открывать и смотреть код проекта.
- Зайди на **code.visualstudio.com** → большая кнопка **Download for Windows** → запусти установщик → «Далее-Далее-Готово».

### б) GitHub Desktop — синхронизация кода с GitHub (без командной строки)
Чтобы код из папки `C:\Traktor` уезжал в твою GitHub-организацию (её ты заводишь по прошлой инструкции). Внутри уже есть Git — отдельно ставить не нужно.
- Зайди на **desktop.github.com** → **Download** → установи → войди своим GitHub-аккаунтом.
- Позже я подскажу по шагам, как «привязать» папку `C:\Traktor` и нажать одну кнопку **Push**, чтобы код улетел на GitHub.

*(Google Chrome, скорее всего, уже стоит — он пригодится, чтобы смотреть веб-версию приложения. Если нет — поставь с google.com/chrome.)*

Всё. Этого достаточно, чтобы мы работали дальше.

---

## 2. Как ты увидишь работающее приложение — 2 пути

### Путь А (рекомендую новичку): ничего тяжёлого не ставишь
Я настрою автоматическую сборку в облаке (GitHub Actions). Дальше:
- **Веб-версия** — открываешь ссылку в браузере и смотришь приложение. Ставить ничего не надо.
- **Android** — скачиваешь готовый файл `.apk` и ставишь на свой Android-телефон как обычное приложение.
Тебе не нужны ни Flutter, ни Android Studio — всё соберётся за тебя.

### Путь Б (по желанию, если захочешь запускать сам): полный набор разработчика
Это мощнее, но тяжелее (несколько гигабайт и больше шагов):
- **Flutter SDK** (flutter.dev) + **Android Studio** (для эмулятора телефона).
- Ставится по официальной инструкции; я проведу тебя по шагам, если решишь.
Нужно только если хочешь сам нажимать «запустить» на своём компе. Для начала — не обязательно.

## 3. Важно про iPhone
Ты на **Windows**, а приложение для **iPhone можно собрать только на Mac** (правило Apple).
- **Android и веб** — делаем полностью на твоём Windows/в облаке, всё ок.
- **iPhone-сборку** сделаем позже: либо на любом Mac, либо через «облачный Mac» (платный сервис на время сборки). Это не срочно — на этапе, когда пойдём в App Store. Сейчас не блокирует.
