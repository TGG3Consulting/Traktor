## 1. GitHub — где будет жить код

**Что это:** «облачная папка» для кода, куда я складываю файлы и веду историю изменений.

Шаги:
1. Зайди на **github.com**, нажми **Sign up**. Заведи аккаунт на свою рабочую почту.
2. Подтверди почту (придёт письмо).
3. Создай **организацию** (не просто личный аккаунт): справа вверху «+» → **New organization** → выбери бесплатный план (Free).
4. Придумай короткое имя организации, например `traktor-am` (латиницей, без пробелов).

**Что прислать мне:** имя организации (например `github.com/traktor-am`). Пароль — нет, только имя.

## 2. Домен + Cloudflare — адрес приложения в интернете

**Что это:** «имя сайта», например `getraktor.com`. Cloudflare — сервис, через который мы этим доменом управляем (и он же наш «щит» и хранилище картинок).

Мы раньше выбрали: свободны `getraktor.com` (проще и дешевле) и `traktori.am` (армянский, но дороже). Рекомендую взять **getraktor.com** — быстрее и ~$10/год.

Шаги:
1. Зайди на **cloudflare.com** → **Sign up**, заведи аккаунт на почту, подтверди.
2. Купить домен проще всего прямо в Cloudflare: слева в меню **Domain Registration → Register Domains**, введи `getraktor` — если `.com` свободен, оформи покупку (нужна карта).
   - Если хочешь именно `.am` — его в Cloudflare может не быть; тогда купи `traktori.am` у армянского регистратора (например **hayhost.am**), а управление позже подключим к Cloudflare. Но для старта достаточно `.com`.
3. Всё. Дальше настройку адресов (DNS) сделаю я с тобой — ничего руками пока не трогай.

**Что прислать мне:** какой домен купил (например `getraktor.com`).

## 3. Google Cloud (GCP) — где работает сервер

**Что это:** «облако», где крутится серверная часть приложения (база данных, логика аукциона и т.д.).

Шаги:
1. Зайди на **cloud.google.com** → **Get started for free** (или **Console**). Войди своим Google-аккаунтом (или заведи новый на рабочую почту).
2. Google даст **бесплатный стартовый кредит** — соглашайся, это нормально.
3. Привяжи карту (**Billing**): меню → **Billing → Link a billing account** → добавь карту. Без этого сервер не запустить. Списаний на старте почти нет (у нас разработка стоит копейки).
4. Создай **проект**: вверху «Select project → New Project», назови `traktor`. Запомни **Project ID** (он покажется, вида `traktor-472913`).

**Что прислать мне:** Project ID (это не секрет) и подтверждение, что карта привязана (billing включён).

## 4. Dexatel — отправка SMS-кодов при входе

**Что это:** сервис, который шлёт пользователю код по SMS, когда он входит в приложение.

Шаги:
1. Зайди на **dexatel.com** → **Sign up**, заведи аккаунт (это бизнес-сервис, могут спросить название компании — можно указать «Traktor»).
2. Напиши им запрос цены. Вот готовый текст, скопируй в их чат/поддержку:

   > Здравствуйте! Планируем OTP-верификацию (SMS с кодом) для мобильного приложения в Армении, объём ~3 000–5 000 SMS в месяц на номера +374. Подскажите, пожалуйста, цену за SMS/верификацию по Армении, поддержку sender ID и доступ к Verify API. Спасибо!

3. Дождись ответа с ценой.

**Что прислать мне:** что аккаунт создан + их ответ по цене (когда придёт).

## 5. Apple Developer — чтобы приложение поставить на iPhone (запусти пораньше!)

**Что это:** платная подписка Apple ($99/год), без неё нельзя выложить приложение для iPhone (даже на тест). **Проверка занимает 1–2 дня и дольше, поэтому начни в первый день.**

Шаги:
1. Заведи (или используй свой) **Apple ID** на **appleid.apple.com**, включи двухфакторную защиту.
2. Зайди на **developer.apple.com** → **Account** → **Enroll**.
3. Выбери тип **Individual / Sole Proprietor** (как физлицо) — это быстрее. *(Вариант «организация» требует спец-номер D-U-N-S и недели ожидания — нам сейчас не нужно; на компанию перейдём позже.)*
4. Заполни данные, оплати $99. Дальше Apple проверяет аккаунт — жди письмо с подтверждением.

**Что прислать мне:** что enrollment запущен (и потом — что подтвердили).

## 6. Google Play — для Android (можно позже)

**Что это:** аккаунт разработчика Google для публикации Android-приложения. **$25 один раз** (не в год).

Шаги:
1. Зайди на **play.google.com/console** → зарегистрируйся своим Google-аккаунтом.
2. Оплати $25, заполни профиль разработчика.
3. *(На заметку на будущее: у новых личных аккаунтов Google просит перед публикацией собрать ~12 тестировщиков на 14 дней — но это уже на этапе выпуска, не сейчас.)*

**Что прислать мне:** что аккаунт создан (когда дойдёшь до него).
