Поток: ставка в аукционе (бюджет ≤ 2 с)

клиент (Idempotency-Key) → gateway → auction: lock(jobId) → валидации → txn{ставка + лидер + антиснайпинг + outbox} → 200 за ~50 мс
→ релей → BidPlaced → notifications (push «перебили») + Centrifugo → все экраны аукциона обновлены < 1 с
финиш: timer-wheel → скоринг → AuctionFinished → deals открывает окно решения 12 ч

Поток: продление аренды (§5.3)

клиент «+2 ч» → deals: проверка соседней брони (локально) → максимум и цена → запрос → push исполнителю → подтверждение 1 тапом →
txn{UPDATE booking.period (EXCLUDE-constraint гарантирует непересечение) + строка сметы + outbox} → RentalExtended → счётчик у заказчика обновлён
нельзя продлить → кандидаты «перехвата» из catalog+search
