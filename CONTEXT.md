# Traktor — паспорт проекта (для продолжения работы в новом чате)

> ⚠️ СНАЧАЛА ЧИТАТЬ `ORCHESTRATOR.md` — там ритуал старта сессии, карта файлов и жёсткие правила. Этот CONTEXT.md — шаг 2 ритуала.

## Что это
Мобильное приложение-маркетплейс заданий для техники (Армения, валюта AMD).
Заказчики публикуют задания (выкопать траншею, перевезти груз и т.д.) с ценой;
владельцы техники откликаются или торгуются в ОБРАТНОМ АУКЦИОНЕ
(ставки вниз, автовыбор победителя по дедлайну, но заказчик вправе отказаться).

## Ключевые решения (утверждены владельцем проекта, Тигран)
- Стек (v1.2, актуально — детали в docs/arhitektura-v1.md): Flutter 3 — ТОЛЬКО клиенты
  (mobile + web + админка), Riverpod + go_router. Бэкенд — 9 сервисов на Go, GCP Cloud Run,
  Postgres+PostGIS (Firestore ИСКЛЮЧЁН), Centrifugo (realtime), Cloudflare R2, MapLibre/OSM.
  Firebase — только FCM/Crashlytics/Analytics/RemoteConfig.
- Языки: hy / ru / en. Темы: светлая + тёмная.
- Скоринг победителя аукциона: цена 60% + рейтинг 25% + расстояние/соответствие 15%.
- Антиснайпинг: ставка в последние 5 мин продлевает аукцион на +10 мин.
- Окно решения заказчика после финиша: 12 ч (подтвердить / выбрать другого / отказаться без штрафа).
- Контакты сторон раскрываются только после подтверждения сделки.
- Встроенный CRM: у исполнителя «Мой бизнес» (доход, воронка, загрузка техники,
  календарь, клиентская база, экспорт XLSX), у заказчика «Мои расходы»
  (по категориям и объектам, избранные исполнители, «нанять снова»).
- Монетизация: v1 бесплатно, v2 комиссия 5–8% + эскроу (Idram/Telcell).
- Имя: бренд «Traktor», в сторах составное имя («Traktor — техника и задания»).
  traktor.am и traktor.app ЗАНЯТЫ (deep links в ТЗ §1.9 заменить!); свободны traktori.am / getraktor.com — домен выбрать и купить (за Тиграном).
- SMS-OTP: Dexatel Verify API + собственный identity-сервис (JWT), не Firebase Phone Auth ($0.17/SMS).
- Юрлицо: ООО в Армении оформляется параллельно разработке (за Тиграном); IT-льгота 1% — уточнить у юриста.
- ЛОГОТИП/БРЕНД — ГОТОВ (13.08.2026): концепт B «T-балка». Брендбук в design/brand/
  (logo-icon*.svg, logo-mark.svg, tokens.css, tokens.dart, brand-kit.html).
  ⚠️ Весь визуал — ТОЛЬКО из брендбука: никаких других цветов/логотипов/шрифтов.

## Как проверять (на компьютере, без терминала)
Скрипты лежат в `C:\Traktor\scripts`, запускаются двойным кликом, результат пишется
в `scripts\_out\*.txt`:
- `check-all.bat` — формат, сборка, vet и тесты всех трёх Go-сервисов.
- `smoke.ps1` (через `run.bat`) — поднимает три сервиса на портах 18080–18082
  и проходит весь путь пользователя через шлюз.
- `pg-test.bat` — поднимает Postgres в Docker и гоняет интеграционные тесты БД.
- `probe.bat` — что установлено в системе (go/flutter/docker/git/node).

⚠️ Порты 8080–8082 на машине заняты Docker/WSL — для локальных запусков берём 18080+.
