# Traktor — открытые вопросы: исследование и рекомендации
*Версия 1.0 — 13.08.2026. По ТЗ §4.6. Статус: на решении у Тиграна.*

## 1. Название «Traktor» и домен

**Факты:**
- «TRAKTOR» — зарегистрированная торговая марка Native Instruments (DJ-софт и оборудование, приложения Traktor DJ 2 / Traktor Pro в App Store). Класс товаров другой (музыкальный софт vs маркетплейс услуг техники), но точное совпадение имени в сторах — риск отклонения/путаницы.
- `traktor.am` — **занят** (домен резолвится).
- `traktor.app` — **занят** (⚠️ в ТЗ §1.9 deep links прописаны на `traktor.app` — надо заменить).
- Свободны (нет DNS-записей, требует подтверждения у регистратора): `traktori.am`, `traktor.io`, `getraktor.com`.

**Рекомендация:** бренд «Traktor» оставить, но:
1. В сторах публиковаться под составным именем: **«Traktor — техника и задания»** (арм. «Տրակտոր», рус./англ. варианты). Составное имя снимает конфликт точного совпадения.
2. Домен — выбрать и сразу зарегистрировать один из свободных вариантов (проверить у регистратора internic/amnic): `traktori.am` / `getraktor.com`, либо подобрать ещё (напр. `traktor-app.am`, `traktorgo.am`).
3. Зарегистрировать ТМ в Армении (AIPA) на класс 35/42 — параллельно с юрлицом.
4. Запасные имена (если стор всё же отклонит): **TraktorGo**, **Traktori**.

## 2. SMS-провайдер для OTP

**Факты:**
- Firebase Phone Auth: SMS в Армению — **$0.17 за SMS** (после 10 бесплатных в день). 1000 регистраций ≈ 1300 SMS ≈ **$170–200**. Дорого и не контролируем sender name.
- Dexatel — армянская компания (Ереван), Verify API (SMS/Viber/Telegram/Flash Call), оплата per-verification, без абонплаты. Точная цена по Армении — через калькулятор/сейлз (локальные армянские SMS обычно в разы дешевле $0.17).
- В ТЗ уже заложен fallback: вход по коду из Telegram-бота (фиче-флаг).

**Рекомендация (гибрид):**
- OTP отправляем через **Dexatel Verify API** из Cloud Functions, после проверки кода выдаём **Firebase Custom Token** → вся остальная архитектура Firebase Auth сохраняется без изменений.
- На этапе разработки/тестов — Firebase Phone Auth в тест-режиме (бесплатно, без реальных SMS).
- Действие: запросить у Dexatel цену за SMS-OTP по Армении на объём ~3–5 тыс/мес.

## 3. Юрлицо

**Факты (2026):**
- ООО в Армении регистрируется за **2 рабочих дня**, нужен юр. адрес.
- Налог с оборота для услуг: базово 10% (с вычетом документированных расходов эффективно ~5–6%). Порог ~115–120 млн AMD, дальше — НДС 20% + прибыль 18%.
- IT-льгота 2025–2032: **1% с оборота** для сертифицированных высокотехнологичных компаний (до 120 млн AMD) + льготы по подоходному. Применимость к маркетплейсу надо уточнять у юриста — выручка платформы (комиссия) может квалифицироваться как IT-услуга.

**Рекомендация:**
- Для v1 (бесплатной) юрлицо не блокер: аккаунты Apple Developer ($99/год) и Google Play ($25) можно открыть на физлицо. Но аккаунт организации выглядит доверительнее (имя разработчика в сторе).
- Начать оформление ООО параллельно этапам 1–2, чтобы к v2 (комиссия + эскроу Idram/Telcell) уже иметь юрлицо, банк и заявку на IT-сертификацию.
